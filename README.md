# Motor-LLM QA Corpus

该仓库是电机领域推理QA语料的持久化、审计和版本治理仓库。

## 基本原则

- 先定义域合同和物理/数学边界，再生成候选分片；
- 所有公式必须独立重算，所有结论必须受证据、模型和授权范围约束；
- 原始分片、失败审计和修复版本不可覆盖；
- 候选数量、确定性审计通过和训练批准必须分开统计；
- 任何现场故障、风险、维修、运行或操作结论必须由合适证据和授权流程决定，E0/G1教学数据不得替代该流程。

## 目录

- `contracts/`：域合同
- `shards/`：不可变JSONL分片
- `audits/`：审计结果
- `repairs/`：修复血缘与回归
- `manifests/`：分片清单
- `registry/`：总体目标、进度和审计状态
